# roadmap; shrinking it requires a tracked issue.

# Node IDs are written against the ceph/s3-tests revision pinned as
# S3_TESTS_REF in run-s3-tests.sh. Bump the pin and the IDs together.
#
# What limits this list today is not the API surface but s3-tests' own
# teardown. Its autouse setup_teardown fixture calls nuke_prefixed_buckets on
# every test, which walks each leftover bucket with ListObjectVersions and
# empties it with DeleteObjects. aks3 implements neither, so a test that leaves
# a bucket behind errors in teardown no matter what the test itself did. Every
# entry below is therefore a test that ends with no bucket of its own: the
# happy-path object and listing tests are blocked on those two operations, not
# on the behaviour they check.
#
# Landing ListObjectVersions (an unversioned store answers with one version per
# key, "null") and DeleteObjects unblocks the bulk of the core suite in one go,
# and is the first thing Phase 1 should do to this file.
